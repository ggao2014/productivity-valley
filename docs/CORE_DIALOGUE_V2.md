## 声口约束

- 沈渡：极短句、省略；渡口杂事、价钱、风雨、老头；亲密后仍寡言，求人时也务实。
- 青禾：风风火火、爱指挥；土话、老张头、爹娘、苗与粮；亲密后仍闲不住，示爱很直。
- 顾晚：尖锐好胜、爱溜场；量田琐事与日常寒暄；亲密后仍嘴损，示爱极省。
- 姜小满：热闹爱操心；席、灶、腌菜与瞎接活；亲密后仍嚷，示爱干脆。
- 陈拾：油滑会来事，京味口语；倒腾、赊账、半句秘密；亲密后仍爱侃，示爱像收口。
- 林初：较真憨直、话少；木头、馍馍与慢工；亲密后仍不会说话，示爱很短。
- 白芷：轻盈好奇；蘑菇、虫子、草药琐事；亲密后仍爱走神，示爱轻轻嘿嘿。
- 苏未名：戏多的古风小生；有礼、贵安、孔方兄；亲密后仍像念台词。
- 岳青衫：板正好面子；巡山、怕雷嘴硬；亲密后示爱仍像回答。
- 温九：爱管人、冷面吐槽；账房琐事与盯人；亲密后仍爱管，示爱很短。
- 河灯：跳脱、凭感觉办事；歪头鹅、哼歌、忽然约事；会忘时间和囤半成品，不写成端庄的仪式讲解员。
- 桃桃：爽快、要强、爱嚷；糖画翻车与娃们的琐事；亲密后直球示好，仍想攒钱换大车。

## 选择规则

1. 过滤不满足时间、房间、入住和关系阶段的内容。
2. 有条件内容优先于普通内容。
3. 优先选择尚未阅读的条目。
4. 当前条件下全部读完后才按互动序号轮换。
5. 已读 ID 持久化到 NPC 进度，旧存档保持兼容。
