# 核心角色个人设定图 v2

共同规则：

- `core-lineup-v3.png` 是唯一身份参考。
- `valley-base-v1.png` 是媒介和世界风格参考。
- 每张包含一个主要正面三分之二全身、一个背面三分之二全身、五个半身表情。
- 五个表情顺序：平静、开心、担心、生气、害羞。
- 不添加文字、标签、边框或新道具。
- 表情只改变眉眼和口型，不改变脸型、发型和年龄。

## 沈渡不变量

- 修长成年男性，长椭圆脸、柔和下颌
- 平直低眉、稍垂的温和眼型
- 整齐低髻，额头清楚，无长侧发
- 灰绿短外衣、月白交领、深色腰带、棕裤
- 竹篙只出现在主全身像
- 姿态安静、笔直、克制

## 顾晚不变量

- 肩线比沈渡宽，棱角脸和清楚下颌
- 上挑眉、锐利微挑眼型、略带嘲意的嘴角
- 凌乱高髻和一绺明显长侧发
- 烟棕围巾、陶土红及膝分衩长衣、深色内层
- 闭合油纸伞只出现在主全身像
- 姿态倾斜、不对称、带防备感

## 桃桃不变量

- 成年女性，温暖椭圆脸和活泼圆眼
- 双环髻与胭脂发带
- 蜜糖黄上衣、胭脂围裙、棕裤、红布鞋
- 铜勺与兔糖只出现在主全身像
- 姿态轻快，但不能幼儿化
