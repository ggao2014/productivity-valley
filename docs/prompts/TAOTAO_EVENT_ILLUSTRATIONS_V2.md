# 桃桃关系事件插画 V2

## 共同约束

- 用途：3:2 横向关系事件插画，运行时导出为 1200×800 WebP。
- 桃桃身份以 `art-source/characters/core/taotao-sheet-v2.png` 为准：成年女性比例、双环髻、红发带、姜黄交领上衣、砖红围裙、深色腰带和宽松棕裤。
- 画风沿用 V1 事件图的暖色水彩、彩铅与细墨线纸张质感，不使用 Q 版或亮面动画渲染。
- 旧铜勺是职业提示，但不再以糖兔或赠送糖果作为画面中心。
- 不出现可辨识文字、现代物品、水印、边框或多余前景人物。

## 友情：自己的招牌

集市收摊后的午后，桃桃站在自己新做好的实用折叠木制糖画摊车旁，用小刷子为木招牌画下最后一笔装饰纹样。玩家只通过一只扶住招牌边缘的第一人称手出现。旧铜勺挂在车边，摊车结构和工作用途在缩略尺寸下仍应清晰。桃桃神情专注、平静而自豪；重点是她建立自己的营生，不是递送可爱礼物。

## 爱情：留一个位置

黄昏散集后，同一辆折叠摊车停在回村土路上。车侧新增一个清楚可见、特意空着的窄木座位。桃桃一手搭着座位，回头看向玩家，神情疲惫但亲近；玩家只通过一只伸向车把的第一人称手出现。远处是收起的棚布、瓦房、低山和初亮的窗灯。爱情由共同收摊、同行和预留的位置表达，不出现糖果、拥抱或戏剧化姿势。
