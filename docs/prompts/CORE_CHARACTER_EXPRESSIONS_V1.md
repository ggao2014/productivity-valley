# 核心角色表情差分 V1

三张素材均以既有成人半身像作为 edit target，锁定角色身份、服装、姿势、道具、构图、画布、线条与设色，只改变面部微表情。

## 沈渡 · warm

- 面部：非常轻微的闭嘴微笑，眼神和眉峰放松。
- 情绪：安静、可靠，像在温和地安慰信任的人。
- 禁止：幼态、夸张笑容、Q 版化、改变低髻或竹篙。

## 顾晚 · annoyed

- 面部：一侧眉峰略高，眼睛轻微眯起，闭嘴且带克制的怀疑感。
- 情绪：像在说“我可没在等你”，别扭但不敌对。
- 禁止：愤怒、凶狠、张嘴、改变高髻乱发、围巾或肩伞。

## 桃桃 · warm

- 面部：自然明亮的闭嘴笑容，眼睛因笑意略弯，脸颊轻抬。
- 情绪：收到正中心意的礼物时真诚开心。
- 禁止：儿童化、Q 版化、夸张动漫表情、改变双髻红绳或铜勺。

共同约束：成人面容；保持现有淡彩工笔与彩铅纸感；不添加背景、文字、水印或新物件。
