# 核心角色组 Prompt

> v1 的 2.75 头身成人方案已作废：成年面容与矮厚身体不协调。  
> v2 开始将成人立绘与山谷 Q 版小人分开生产。

## 共同约束

- 参考 `art-source/environment/valley-base-v1.png` 的彩铅、水彩、纸张、线条和色板。
- 三名角色均为成年人；立绘采用 6–6.5 头身，山谷小人另做 3 头身 Q 版。
- 服装为虚构的旧时中式乡野日常服装，不对应具体朝代。
- 五官简化，辨识依靠道具、服色、体态和发型。
- 不出现姓名、标签、标尺、UI、水印或现代物品。

## 三人同框基准图

```text
Use case: illustration-story
Asset type: production character lineup and shared style reference for a cozy game
Input image: use the provided valley baseline only as the reference for colored-pencil line quality, transparent watercolor, warm paper texture, restrained palette, and calm Chinese countryside picture-book world. Do not copy its landscape composition.
Primary request: Show three distinct adult Chinese picture-book characters standing side by side at equal scale as a clean character lineup. They belong naturally in the referenced valley. Use elegant 6 to 6.5-head-tall adult proportions with relaxed shoulders, visible necks, longer legs and naturally sized heads.

Character 1, Shendu: quiet and kind boatman; gray-green and moon-white layered rural clothing; straight relaxed posture; dark hair in a practical low knot; holds one simple bamboo punt pole vertically; restrained, observant expression; long clean silhouette.
Character 2, Guwan: sharp-tongued but soft-hearted traveler; terracotta red and smoke-brown layered rural clothing; dark hair with one slightly loose side strand; holds one closed oil-paper umbrella resting on a shoulder; subtly angled posture and mildly skeptical expression; crisp triangular silhouette.
Character 3, Taotao: cheerful sugar-painting maker; rouge pink and honey-yellow practical rural clothing with a small apron; dark hair gathered into two compact looped buns suitable for an adult artisan; holds one small copper ladle and a simple rabbit-shaped sugar painting; lively forward-leaning posture; round energetic silhouette.

Style/medium: colored-pencil storybook drawing over light transparent watercolor, soft broken dark-brown contours, subtle warm handmade paper grain, same restraint and warmth as the provided valley reference
Composition: landscape lineup; full bodies entirely visible; equal foot baseline; generous space between characters; plain warm paper backdrop with only faint watercolor ground shadows; front three-quarter poses
Lighting/mood: soft diffuse daylight, intimate, calm, gently humorous
Constraints: exactly three people; all visibly adult despite chibi proportions; each has only the specified signature props; clothing silhouettes and main colors clearly different; no text, no labels, no border, no UI, no watermark
Avoid: children, teenagers, photorealism, 3D, anime card art, oversized sparkling eyes, sexualized clothing, ornate palace costumes, xianxia robes, armor, modern fashion, neon colors, pure-black outlines, extra limbs, duplicate props, busy scenery
```

个人设定图必须使用最终三人同框图作为身份、比例和服装参考，并重复角色不变量。
