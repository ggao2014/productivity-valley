# Room interiors v1

Generated with the built-in image generation tool on 2026-07-30. Each image used
its matching exterior room module as a style reference.

## Shared direction

- Use case: illustration-story; landscape room-detail hero.
- Composition: 3:2, straight-on picture-book cutaway, simple large silhouettes.
- Rendering: soft watercolor, restrained colored-pencil texture, warm dark-brown
  outlines, off-white paper grain, gentle natural shadows.
- Palette: sage, honey wood, cream and restrained terracotta.
- Exclude people, text, UI, logos, modern appliances, fantasy effects,
  photorealism, anime rendering and excessive clutter.
