# 房间外观模块 V1

五张素材均以 `valley-base-v1.png` 作为严格的风格、透视、瓦片尺度、材质、色板和漫射光参考。输出为独立建筑模块，使用纯色 `#ff00ff` 背景生成后本地去底。

共同风格：柔和水彩铺色、彩色铅笔细节、深棕手绘轮廓、暖纸纹和轻微纸片拼贴边缘。共同约束：一间房宽度、略俯视正面、白灰墙、深灰弧瓦、暖木构；无人物、地面、景色、路径、文字、UI、水印、投影或额外建筑。

| 房间 | 外部辨识 |
|---|---|
| 卧室 | 一扇小型暖色方格窗，最克制的屋檐 |
| 厨房 | 短烟囱、暖窗、檐下少量香草 |
| 书房 | 较高的窄格窗，窗内低处有两册书影 |
| 客房 | 两扇匹配方窗和一盏小木门灯 |
| 储藏室 | 较低屋顶、小木门、通风口和两只竹筐 |

运行时透明 WebP 位于 `public/art/house/modules/`；原始色键图与透明 PNG 分别保存在 `art-source/house/modules-chroma/` 和 `art-source/house/modules-alpha/`。
