# Phase 3 山谷成长与装饰素材 V1

生成方式：内置 ImageGen。正式运行时素材均转换为 WebP；装饰图集使用洋红色键控背景，并在本地去背、按固定网格切分。

## 四阶段山谷

共同约束：

- 以 `public/art/environment/valley-base-v1.webp` 为编辑参考。
- 保持 3:2 画布、相机、山体、溪流、竹林、主屋轮廓、门窗与路径锚点不变。
- 不改变房间模块连接区、角色站位与 DOM 点击热区。
- 保持方向 C 的彩铅故事书、水彩底色、暖纸张纹理与深棕铅笔线。
- 不绘制角色、文字、UI、边框或水印。

阶段变化：

1. **荒地**：草地稍高且斑驳，路径较窄，屋基有少量杂草；不做破败或阴郁处理。
2. **初步修整**：沿用正式基础山谷，地面和路径已经可读，但尚无明显共同生活痕迹。
3. **温暖小屋**：路径清理、墙边小香草圃、水桶、克制炊烟与柔和窗灯。
4. **有人生活的家**：两只茶杯、短晾布、小扫帚、花圃、炊烟与双窗灯；不出现人物。
