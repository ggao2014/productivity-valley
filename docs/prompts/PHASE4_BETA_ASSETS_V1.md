# Phase 4 封闭测试素材 V1

生成方式：内置 ImageGen。

## 测试版封面与分享图

宽幅彩铅故事书山谷，晚春柔光中的白墙黑瓦小屋、溪流、弯曲小路；前景是一页带勾选的待办本、绿色铅笔与两杯茶。左上保留 HTML 文案空间，图片本身不含文字、Logo 或 UI。运行时裁切为 1200×630 WebP，同时用于邀请入口与 Open Graph 分享图。

## 四状态图集

2×2 图集依次为：

1. 离线：一扇暖窗的小屋与未连接插头；
2. 更新：两张正在展开的纸页与两片绿叶；
3. 存档恢复：打开的木匣与完整捆扎的纸页；
4. 反馈：信封、绿色铅笔与一朵白花。

使用纯 `#ff00ff` 键控背景、本地去背，切为 320×240 透明 WebP。沿用方向 C 彩铅、水彩底色、暖纸纹理和深棕线条；不使用红色警告、云账号符号、企业技术图标、文字或水印。
