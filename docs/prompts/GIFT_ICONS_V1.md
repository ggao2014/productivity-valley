# 礼物图标 V1

本组图标使用代码原生 SVG，不调用位图生成模型。所有图标集中在
`src/assets/icons/GiftIcon.tsx`，使用 32×32 viewBox、1.65px 圆角描边和一层低透明度底色。

## 视觉语法

- 主体使用深色单线轮廓，避免小尺寸下的内部纹理。
- 每枚图标只保留 1–3 个识别特征。
- 圆形淡色 wash 统一图标占位面积。
- 食物使用姜红或麦金，木器和布袋使用木棕，茶与纸使用苔绿。
- 不在 SVG 中写死界面背景色；颜色由 CSS 的 `currentColor` 控制。

## 识别特征

| 礼物 | 图标特征 |
|---|---|
| 热姜汤 | 汤碗与三缕蒸汽 |
| 麦香饼 | 三层扁圆烤饼 |
| 糖炒栗子 | 纸袋与两颗开口栗子 |
| 小木块 | 有年轮/纹理提示的立体木块 |
| 桂花糖 | 包糖纸与五瓣桂花 |
| 蜜橘皮 | 卷曲果皮与小叶 |
| 小玩意 | 星形挂件与坠穗 |
| 印泥 | 圆盒、红泥内圈与小印章 |
| 暖手豆袋 | 缝线布袋与分格 |
| 麦芽糖 | 糖罐与拉丝线 |
| 茶饼 | 圆茶饼与叶形压纹 |
| 莲纸 | 叠纸、折角与莲花线稿 |

## 验收

- 在 44px 商店尺寸与 24px 辅助尺寸下均能辨认。
- 禁用按钮降低整体透明度后，轮廓仍然完整。
- 图标不依赖文字或颜色才能区分。
