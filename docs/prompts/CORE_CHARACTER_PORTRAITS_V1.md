# 核心角色对话半身像 v1

生成方式：内置图像生成工具。分别使用三人的 v2 个人设定图作为唯一身份参考，在纯青色 `#00FFFF` 背景上生成，再移除色键、裁切透明边缘并压缩为透明 WebP。

共同要求：

- 成人近景比例，不使用 Q 版脸
- 腰部以上、正面三分之二视角
- 平静且带角色性格的默认表情
- 保留完整发型剪影
- 一个不遮脸的专属道具提示
- 不改变脸型、年龄、发型、服装或主色
- 无场景、文字、边框、UI 和地面阴影

角色默认状态：

- 沈渡：平静观察，轻微温和；远肩后露出一段竹篙
- 顾晚：怀疑中带一点笑意；闭合油纸伞横在远肩后
- 桃桃：明亮平静的小笑；铜勺位于画面外侧下方

源文件：

- 透明 PNG：`art-source/characters/portraits-alpha/`
- 部署 WebP：`public/art/characters/portraits/`
