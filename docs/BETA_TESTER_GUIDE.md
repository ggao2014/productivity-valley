# 山谷 v0.9 封闭测试者说明

谢谢你来照料这座还在生长的山谷。

## 如何进入

打开邀请人发来的链接。如果链接没有自动放行，请输入邀请码：

```text
SHANGU-09
```

测试版不会创建账号。待办、人物关系、房间和其他进度只保存在你当前使用的浏览器或已安装应用中。

## 希望你怎样使用

- 按真实需要写待办，不需要为了测试每天签到。
- 可以跳过一天，也可以隔几天再回来；山谷没有断签惩罚。
- 自然地与角色聊天、买房、送礼或装饰山谷，不必刻意刷进度。
- 如果愿意参与匿名统计，到“口袋 → 测试与隐私”打开开关。测试第 1/7 日从你打开开关时开始计算。
- 建议在第 7 天和第 14 天各导出一次反馈。

## 如何反馈

点击页面顶部的“测试反馈”：

1. 回答四道简短问题；
2. 写下任何让你想继续或让你停住的地方；
3. 点击“下载反馈文件”；
4. 先自行查看 JSON 内容，再决定是否发给邀请人。

应用不会自动上传反馈或匿名事件。

## 数据与隐私

匿名事件默认关闭。打开后只记录：

- 首次完成待办与核心循环；
- 友情/爱情阶段；
- 购买房间；
- 第 1 天和第 7 天回来。

不会记录待办标题、角色对话、姓名、邮箱、设备标识或网络地址。关闭开关会立即清空本机匿名事件。

## 存档保护

- 请勿在测试期间清除该站点的浏览器数据。
- 可以从“口袋 → 存档”定期导出 JSON 备份。
- 换浏览器或换设备前先导出，再在新设备导入。
- 如果看到存档恢复提示，请在反馈中选择“错误或存档问题”，并说明发生前做了什么。

## 安装与离线

- iPhone/iPad：Safari 分享 → 添加到主屏幕。
- Chromium 浏览器：使用页面底部安装提示或浏览器菜单中的“安装应用”。
- 第一次完整联网打开后，已访问的主要内容可以离线使用。

测试目标不是证明你有多自律，而是判断这座山谷是否真的值得回来。
