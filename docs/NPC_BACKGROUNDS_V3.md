# 镇民背景设定 V3

本文件记录角色剧情的事实基准。`NPC_VOICE_BIBLE.md` 负责“怎样说话”，本文件负责“为什么成为这样的人”。后续新增日常、事件与礼物反应时，不应随意增加悲惨身世，也不能让亲密关系治愈角色的全部缺点。

## 沈渡

- **出身**：老摆渡人的孙子。年轻时跟过几年船队，近年回乡替年迈的爷爷摆渡。渡河五文钱，勉强填饱肚子。
- **形成性事件**：暂无单独高光事故；日常就是赶羊赶牛、停风停雨、看破桥、看栈桥，以及半夜去逮凫水的娃子。
- **现在想要的**：把渡口撑到爷爷走完；私下里说，送走老头后就不在这儿划船了。
- **缺点**：话极少，关心人也不多说；对加钱开船、站船头、乱碰东西没耐心。
- **关系线**：友情是一起坐着、泡脚、听他抱怨渡口杂事；爱情可以很实际——屋顶漏了，问你有没有空房间。始终寡言。

## 青禾

- **出身**：租田种粮，也卖粮种。常给爹娘送馍馍，闲下来会给娘帮厨。
- **形成性事件**：跟邻地老张头结了梁子——前年他偷切水渠，两人打了好久；如今她天天盯着，看他还敢不敢偷。老张头荒地自己不开，却惦记她养好的地。
- **现在想要的**：把这季种稳，苗不焦、种留得住；家里菜圃归置得齐齐整整。
- **缺点**：风风火火、爱指挥，活抢到手才安心；说话快，嫌人磨叽，旧箱子说撇就撇。
- **关系线**：友情是一起通沟、认杂草、骂老张头；爱情直白——“我也稀罕你”，关心人像赶你回屋喝水。搬走了也说有事还叫我，别生分。

## 顾晚

- **出身**：替人量田画图，也会做伞。姐姐搬走前做的那把伞，他用到现在还好好的。
- **形成性事件**：常被村头扯皮两家夹在中间；界桩丢了、水渠吵了，他照章办事，整得左右不是人，气急了就溜。
- **现在想要的**：攒钱买块好墨；有间向阳的房放图，窗边潮的不行。
- **缺点**：尖锐好胜，爱挑刺儿；被请吃饭也改不了田界。知道自己嘴损，偶尔会道歉。
- **关系线**：友情是一起测绘走错路、分半个馍馍、给人画像；爱情很省话——“我听见了”。搬走也说别难过，有缘再见。

## 姜小满

- **出身**：小时候家里卖面，来人都喊她“小掌柜”。跟哥哥爱啃面头子。长大后办席掌勺，也爱腌菜。
- **形成性事件**：席多、账难要、盐放多、陈拾瞎接活——日子多半围着灶台转；忙起来连口水都顾不上喝。
- **现在想要的**：把席办稳，秋菜一来先腌上三坛；才不要开累死人的大酒楼。
- **缺点**：热闹、爱操心、嗓门大；火一旺就喊，锅借出去还黏也会念叨。
- **关系线**：友情是一起救咸汤、帮大席、学慢慢腌菜；爱情直白——“好啦，我也喜欢你”。搬走前叮嘱厨房剩菜别搁太久。

## 陈拾

- **出身**：货郎，啥都倒腾。靠一张嘴跑生意，十里八乡都熟。
- **形成性事件**：爱赊账、爱捎话、爱说“不能说”的秘密；替青禾买家伙式儿、找沈渡还船钱，热心里掺着生意经。
- **现在想要的**：买卖周转得开，乡里乡亲赊个账也不怕；得空买个新账本。
- **缺点**：油滑、会来事、嘴停不住；谈钱先打哈哈，消息藏半句。
- **关系线**：友情是一起赶集、听秘密、托他办事；爱情仍像卖货收口——“我喜欢您。货真价实”。搬走说后会有期。

## 桃桃

- **出身**：家里开糖食作坊，嫂子画龙最传神，她自己走村赶集卖糖画。铜勺旧了也不换。
- **形成性事件**：集上常碰到砍价的、认错图样的、舔糖浆的娃；她又气又惯，嘴上不停。
- **现在想要的**：攒钱换一辆带阳棚的大车，让镇上的娃都知道“桃桃的糖画”。
- **缺点**：要强、爱嚷、翻车先嘴硬；东西糊了也硬说甜，凤凰被认成小鸡会急。
- **关系线**：友情是一起收摊、看小猫、搓顿好的；爱情很直白——糖兔子、留座、喜欢你。搬家时会塞你一怀东西就走。

## 林初

- **出身**：木匠。师父嫌他慢，他心里再急手上也快不起来。第一张凳子腿长短不一，现在还垫着箱子。
- **形成性事件**：差一线就要重做；顺手给人雕小狗、打椅子，收费常说不用给。话少，觉得跟木头打交道更省心。
- **现在想要的**：把活干扎实；二里沟修犁、栈桥查梁，托他的事一件件做完。
- **缺点**：较真、憨直、话少；慢工，急也快不了。
- **关系线**：友情是递馍馍、塞木雕、打新椅子；爱情直白一句“我喜欢你”。搬走时把凿子留下。

## 白芷

- **出身**：采药晒药，收集标本。认药不看病。药铺贴错标签会气得说岂有此理。
- **形成性事件**：日常就是采蘑菇、晒药、压叶子、追老鼠；草药被当杂草扔、被小满炒进锅，都会哇哇叫。
- **现在想要的**：药圃能下脚，标本别受潮；山谷每个季节的花草都想记一记。
- **缺点**：轻盈好奇，容易走神；越说别碰大家越碰，自己也会先兴奋后补一句。
- **关系线**：友情是尝花、喝百草茶、指着同名的白芷草；爱情轻轻一句“我喜欢你。嘿嘿”。搬走只说那我走啦。

## 苏未名

- **出身**：代写书信，也爱写故事。考了十年不中，给人写信渡日。满口小生、足下、贵安。
- **形成性事件**：日常开口先有礼；被人笑酸腐会急；谈钱叹孔方兄；偶感风寒也要文绉绉见谅。
- **现在想要的**：文章被人看见；眼下先把信写完、稿箱安顿好。
- **缺点**：戏多，套话循环使用；得意时哎呀呀，吃瘪时呔一声。
- **关系线**：友情是展示新作、叹孔方兄；爱情是“小生不才，愿为足下效力”。搬走道后会有期了。

## 岳青衫

- **出身**：巡山护路，也教基本防身。习惯早起、列队、巡逻；下雨天更得出去。
- **形成性事件**：怕雷却死不承认，只说担心别人怕；山里有狼会拦人，救小猫也要说成没什么大事。
- **现在想要的**：山路平安，镇上少出事；闲下来反而不知道干什么。
- **缺点**：板正、好面子；催人跟上，休息日也要打三遍拳。
- **关系线**：友情是提醒狼患、塞木哨、一起晨巡；爱情像汇报——“回答如下：我也喜欢你。”搬走道那就后会有期。

## 温九

- **出身**：在镇上做账房先生。以前在大宅管账，东家忘了的事都来问他。
- **形成性事件**：天天和铜钱、坏账、字迹鬼画符打交道；爱管靴子乱扔、门闩灭灯、谁不敲门，嘴冷心细。
- **现在想要的**：账对齐、公屋修缮落账；别人说他记性好，他反而不敢忘。
- **缺点**：爱管人、冷面吐槽；椅子挪了都要问，也会忽然问你会不会觉得我烦。
- **关系线**：友情是催账、骂字迹、记公屋；爱情一句“我喜欢你”，然后立刻催你看信。搬走钥匙放书房，账两清了。

## 河灯

- **出身**：灯匠。做纸灯、路灯、船灯，也爱做歪头鹅。小时候怕黑，现在也有点怕。
- **形成性事件**：放灯节后总去下游捞湿灯；灯棚里练手的半成品舍不得扔。二里沟路灯、沈渡船灯她都记着数。
- **现在想要的**：把订单一盏盏做完，再找人放风筝、赶集、看太阳出来。
- **缺点**：跳脱、凭感觉办事，爱哼歌跑题，算灯油行、算时间不行；不干啦说完还能再干一会儿。
- **关系线**：友情里分享怕黑和小秘密；爱情里白天也黏人，示爱写了好长一段最后只说喜欢你。
