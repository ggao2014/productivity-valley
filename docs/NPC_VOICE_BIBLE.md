# 镇民性格与声线基准 V3

本文件优先于“职业知识是否完整”。镇民可以把事情做得专业，但不能因此都说成冷静、谨慎、善于解释边界的成年人。日常对话首先要让玩家认出“是谁在说话”，其次才传递职业信息。

## 写作硬规则

1. 一条普通聊天只承担一件事，避免每句话都同时包含事实、边界、反思和正确结论。
2. 至少三分之一的日常聊天必须与“职业教学”无关，可以是抱怨、闲话、误会、食物、天气、别人或无意义的小发现。
3. 每人至少保留一个不会被关系成长彻底治好的缺点；亲密不是人格矫正。
4. 不让镇民替产品讲道理。诸如“先取得同意”“公开说明”“保存也该有期限”等原则，只能通过具体事件和后果表现，不能反复成为口号。
5. 删除全员通用的稳妥句式：`谢谢，我收下了`、`心意我知道`、`你不用找理由`、`一起商量`、`我会认真用`。送礼、喝茶和入住也必须有各自的脾气。
6. 事件结尾不强制总结成长。允许以尴尬、笑场、争执未完、一个动作或一句跑题的话收尾。

## 一句话辨声测试

隐藏名字和职业名词后，台词仍应大致可辨：

- 沈渡：“加钱也没用，风太大了。”
- 青禾：“别傻站着，帮把手。”
- 顾晚：“溜了溜了。”
- 姜小满：“吃了没？”
- 陈拾：“嘿嘿，谈钱伤感情。”
- 桃桃：“什么小鸡！我画的是凤凰！”
- 林初：“不行不行，得重做。”
- 白芷：“别动别动！你肩上有只虫，好漂亮。”
- 苏未名：“小生这厢有礼了。”
- 岳青衫：“雷...我不是怕打雷！担心你怕而已。”
- 温九：“你会不会觉得我烦？”
- 河灯：“嘻嘻，这盏歪头鹅灯你喜欢吗？”
